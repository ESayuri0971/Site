# SINTAXE — Landing Page para Curso de Programação

Website completo e responsivo construído com base nos componentes e Design System do **Forma AI** (`forma-ai.aura.build`).

## 📁 Estrutura de Arquivos

- `index.html`: Página completa com todas as seções, interações em JavaScript puro, Tailwind CSS e fontes do Google Fonts.
- Componentes integrados:
  - Header fixo com efeito de vidro fosco (`backdrop-blur-xl`) e atalho `⌘ K`.
  - Hero com títulos intercalados em *Instrument Serif Italic*, subtítulo e **Course Explorer interativo**.
  - Faixa de credibilidade e pilares pedagógicos.
  - Seção de Metodologia em 3 fases (Fundamentos, Engenharia Moderna, Escala & IA).
  - Vitrine de 3 projetos reais de portfólio com hover 3D e elevação suave.
  - Manifesto editorial em tipografia de grande porte.
  - Grade curricular completa com 6 módulos.
  - Tabela de preços interativa com alternador parcelado / à vista (com desconto de 20%).
  - Sanfonas de Perguntas Frequentes (FAQ).
  - Chamada final para ação com anéis concêntricos de calor em cobre.
  - Rodapé editorial com marca d'água gigante.
  - Modal de navegação rápida por teclado (`Cmd + K` / `Ctrl + K`).
